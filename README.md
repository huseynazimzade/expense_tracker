# Expense Tracker (Xərc İzləyici)

Flutter vasitəsilə hazırlanmış sadə və istifadəçi dostu şəxsi xərc izləmə tətbiqi. Bu tətbiq vasitəsilə günlük xərclərinizi kateqoriyalara görə qeyd edə və ümumi məbləği izləyə bilərsiniz.

## 🚀 Əsas Xüsusiyyətlər
* Kateqoriyalar üzrə xərclərin qeydiyyatı (Qida, Nəqliyyat, Əyləncə və s.)
* Xərclərin ümumi cəminin avtomatik hesablanması
* Səliqəli və intuitiv interfeys
